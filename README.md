# Android Kernel Source for Xiaomi Redmi A4 5G / POCO C75 5G (warm)

This repository contains the Linux kernel source for the **Xiaomi Redmi A4 5G** and **POCO C75 5G** (codename: *warm*), powered by the **Qualcomm Snapdragon 4s Gen 2 (SM4635)**.

## Kernel Details
- **Kernel Version:** 6.1.x
- **Platform:** Pitti (SM4635)
- **Kernel Family:** `UM_6_1_FAMILY` (Compatible with Pineapple/Volcano architectures)
- **Architecture:** arm64
- **GKI Version:** 6.1 (Generic Kernel Image compliant)
